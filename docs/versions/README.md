# IntentFlow Project Versions

The project changed direction several times. These documents preserve the major versions as they were discussed so the evolution is visible. They are historical snapshots, not competing V1 scopes.

1. [Version 1 — Behavioral Intelligence Engine](01-behavioral-intelligence-engine.md): broad user-intent and personalization platform.
2. [Version 2 — Real-Time Session Recommender](02-real-time-session-recommender.md): narrowed RetailRocket portfolio build and 8-phase, 8–10 week outline.
3. [Version 3 — IntentFlow initial differentiation](03-intentflow-initial.md): intent trajectory and robustness as differentiators.
4. [Version 4 — Final IntentFlow plan](04-intentflow-final.md): adaptive compute under latency constraints, three logical planes, replay lab, and a constrained V1.

The current implementation scope is the finalized V1 in `docs/00-project-specification.md`. Earlier versions explain why scope was reduced; do not treat every historical feature as mandatory.
